# Calculator App 🖩

A sleek, responsive calculator built with **HTML, CSS, and JavaScript**, featuring:

- Dark Mode toggle 🌙
- Decimal & percentage calculations
- Basic arithmetic: addition, subtraction, multiplication, division
- Proper handling of floating-point numbers
- Neumorphic design with smooth UI

---

## 🔗 Live Demo

Try it online: [Calculator App Live](https://lambodarbag.github.io/calculatorApp/)

---

## 🛠 Features

- **Responsive Design** – Works on desktop and mobile
- **Dark Mode** – Toggle for night-friendly UI
- **Decimal & Percentage** – Accurate calculations
- **Error Handling** – Avoids invalid inputs and consecutive operators
- **Neumorphic Buttons & Screen** – Modern look

---

## 💻 Tech Stack

- HTML5  
- CSS3 (Neumorphism + Dark Mode)  
- JavaScript (Vanilla JS)
